# Backend

Folder ini digunakan untuk instalasi dan pengembangan aplikasi backend menggunakan Laravel 11.

## Instruksi

Lakukan instalasi Laravel 11 di folder ini.

Contoh perintah:

```bash
composer create-project laravel/laravel:^11.0 .
```

Setelah instalasi selesai, lanjutkan dengan konfigurasi environment, database, migrasi, dan dependency backend yang dibutuhkan proyek.
