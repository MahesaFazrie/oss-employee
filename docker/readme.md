# Docker

Folder ini digunakan untuk menyimpan konfigurasi Docker untuk menjalankan layanan proyek.

## Instruksi

Buat konfigurasi Docker di folder ini.

Konfigurasi yang perlu disiapkan minimal mencakup:

- `docker-compose.yml` untuk orkestrasi layanan.
- Dockerfile backend untuk Laravel 11.
- Dockerfile frontend untuk Next.js.
- Konfigurasi database dan service pendukung lain bila diperlukan.

Pastikan konfigurasi Docker dapat menjalankan backend, frontend, dan database secara konsisten di lingkungan lokal.
