# Docs

Folder ini digunakan untuk menyimpan dokumentasi proyek.

## Instruksi

Buat dokumentasi API Contract di folder ini.

Dokumentasi API Contract perlu mencakup:

- Daftar endpoint API.
- Method HTTP.
- Request headers.
- Request body.
- Response body.
- Status code.
- Contoh payload sukses dan gagal.

Gunakan format dokumentasi yang konsisten agar mudah dipahami oleh tim frontend dan backend.
