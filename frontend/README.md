# OSS Employee - Frontend

This is the frontend application for the Employee One Stop Service Platform (OSS).
It is built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Prerequisites

- Node.js (version >= 18.17.0, tested with 20.x)
- npm (Node Package Manager)

## Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Run the development server**
   ```bash
   npm run dev
   ```
   Then open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Available Commands

- `npm run dev`: Starts the development server.
- `npm run build`: Creates a production-ready build of the application.
- `npm run start`: Runs the production server after a build.
- `npm run lint`: Runs ESLint to catch syntax and style issues.
- `npm run type-check`: Runs TypeScript compiler to catch type errors.
